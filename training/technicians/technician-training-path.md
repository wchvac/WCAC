# Technician Training Path

## Level 1

- Safety
- Customer communication
- Basic tools
- Maintenance procedures
- Documentation and photos

## Level 2

- Electrical diagnosis
- Refrigeration diagnosis
- Airflow diagnosis
- Common repair procedures
- Repair option presentation

## Level 3

- Advanced diagnostics
- System performance analysis
- Callback prevention
- Junior technician coaching
- Replacement opportunity identification

## Sign-Off Rule

Each skill should be demonstrated in the field before being marked complete.
