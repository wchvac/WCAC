# WCAC-OS Software Product Vision

## Goal

Create a simple internal system that helps West Coast Air Conditioning manage daily operations, accountability, gross margin, follow-up, and training.

## Initial Modules

1. Daily huddle dashboard
2. Open-task tracker
3. Estimate follow-up tracker
4. Job-costing calculator
5. Gross-margin dashboard
6. Training checklist
7. Procedure library
8. Management scorecard

## Design Principles

- Mobile friendly
- Low reading
- Simple buttons
- Minimal data entry
- Clear ownership
- Automatic reminders
- Easy reporting
