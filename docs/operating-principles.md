# Operating Principles

## 1. Make It Simple

Every process should be easy to understand and easy to follow.

## 2. Use Checklists

Important work should not depend on memory.

## 3. Measure Gross Margin

Revenue alone does not show whether a job was profitable.

## 4. Follow Up Quickly

Unreturned calls, unsent estimates, and forgotten parts cost money.

## 5. Assign One Owner

Every task must have one person responsible for completing it.

## 6. Close the Loop

A task is not complete until the result is recorded and communicated.

## 7. Train the Same Way Every Time

Standard training creates consistent service.

## 8. Improve the System

When something goes wrong, fix both the immediate problem and the process that allowed it.
